# /media: картинки и видео

Генерацию видео и картинок обычно выполняет человек во внешнем сервисе (например Kling, Seedance, Veo, Midjourney, Flux). Твоя задача: подготовить точный бриф, принять результат, проверить и записать в журнал. Если у тебя есть инструмент генерации, используй его, но по тому же брифу и с записью в журнал.

## 1. Бриф (создай `docs/media-brief.md`)
Для каждой страницы:
- Назначение и сюжет по кадрам (4 кадра по 2–3 секунды).
- Стиль: тёмная тема, пиксельные LED-иконки и сцены, как уличное табло. Без реальных людей, без логотипов, без текста на кадрах.
- Технические требования: 8–12 секунд, горизонтальный кадр 16:9 с безопасной зоной по центру (кадрируется под телефон), без звука, вес до 2 МБ, постер JPG.
- Для A: поток заказов нескольких брендов (разные цвета иконок), кухня, курьеры расходятся по маршрутам.
- Для B: заведение запускает свой канал: появляется приложение, первый заказ, курьер, доставлено.

## 2. Промпты
Структура промпта для ключевого кадра (картинка):
`[сюжет кадра], pixel art LED street display style, dark background, [акцентный цвет из brand.md] glow, clean grid pixels, no text, no people, no logos, 16:9`
Для оживления (картинка в видео):
`[что движется], smooth loop, slow camera push-in, consistent pixel style, no text, no people`
Сначала 4 ключевых кадра картинками, затем каждый кадр оживляется, затем склейка в один ролик. Так проще сохранить единый стиль, чем генерировать ролик одним промптом.

## 3. Журнал
Каждую генерацию добавь строкой в `docs/prompts.md`: дата, материал, инструмент и версия, промпт, референсы, итоговый файл, что поправили вручную.

## 4. Приёмка файлов
- Файлы лежат в `site/assets/media/`, имена латиницей: `hero-kitchens.mp4`, `hero-kitchens-poster.jpg`.
- Вес видео до 2 МБ. Если больше, сжать (если стоит ffmpeg): `ffmpeg -i in.mp4 -vf scale=1280:-2 -c:v libx264 -crf 28 -an -movflags +faststart out.mp4`.
- Картинки до 300 КБ.
- Запусти `node scripts/check.mjs --strict` и убедись, что нет красных пунктов про медиа.
- В отчёте перечисли, что человеку нужно посмотреть глазами (уместность и стиль).
