# /retro: ретроспектива

1. Прочитай `docs/log.md`, `docs/tickets.md`, `docs/feedback.md`, `docs/questions.md`, `docs/handoff.md`.
2. Заполни `docs/retro.md`:
   - Что сработало (2–4 пункта с примерами из лога).
   - Что не сработало или съело время (тикеты с двумя кругами ревью, blocked, правки человека после C2 и C3).
   - Повторяющиеся замечания ревьюера и человека: каждое превращай в предложение правила.
   - Часы по блокам, если человек их назвал. Не выдумывай цифры.
3. Для каждого повторяющегося замечания предложи конкретное изменение: строка для `CLAUDE.md`, правило для `.claude/skills/<имя>/SKILL.md` или новая проверка для `scripts/check.mjs`. Запиши предложения в `docs/retro.md` в раздел «Какие правила добавить». Сам эти файлы не меняй, решает человек.
4. В конце скажи человеку, какое одно изменение даст больше всего пользы в следующий раз.
