# /verify: финальная проверка

1. Запусти `node scripts/check.mjs --strict` и `node --test`. Скопируй результат.
2. Если у тебя есть браузерный инструмент, открой локальный сервер (`cd site && python3 -m http.server 8000`) и пройди сценарии:
   - Форма: пустая отправка, неверный телефон, верная отправка, ошибка (`?simulate=error`), «Повторить».
   - Демо D1–D5 на своих страницах: каждая кнопка, фильтр и переключатель.
   - Ширины 360, 768, 1280. Горизонтальной прокрутки быть не должно.
   Если инструмента нет, не изображай проверку. Запиши «не проверено, нужна проверка глазами».
3. Создай `docs/handoff.md`:

```
# Передача человеку (C3)
Дата и версия проверок.

## Статус критериев
| ID | Статус | Чем подтверждено |
| AC-01 | ok / fail / нужна проверка глазами | auto / test / review / ссылка на файл |

## Результаты запусков
(последние строки вывода check.mjs и tests)

## Что нужно проверить глазами
(по docs/checklist.md, с точными адресами страниц)

## Известные ограничения и допущения
(из docs/questions.md)

## Тикеты в статусе blocked или waiting-human
```

4. Если есть `fail`, перечисли, что исправить, и не говори «готово».
5. В конце напомни человеку: пройти `docs/checklist.md` и отметить C3 в `docs/checkpoints.md`.
