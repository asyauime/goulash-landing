# Чек-лист приёмки (C3)

Автоматически перед каждой выкладкой: `node scripts/check.mjs --strict` и `node --test`. Ниже то, что проверяет человек глазами. Адрес: https://asyauime.github.io/goulash-landing/. Отмечайте `[x]`.

## Узнаваемость и подача (AC-26)
- [ ] Страница выглядит как «Гуляш»: тёмные и светлые секции, LED-точки и пиксельные иконки, белая кнопка CTA
- [ ] Обе роли понятны: гост-китчены по всей странице, рестораны со своей доставкой в блоке «Своя доставка»
- [ ] Тексты звучат как живая речь, без канцелярита и ИИ-штампов; висячих предлогов нет
- [ ] Нет выдуманных цифр в статичном тексте, отзывов и логотипов клиентов
- [ ] Названия демо-брендов и курьеров («Медный котелок», «Луковый сад», «Сытая полка», Илья, Мария, Олег) не совпадают с реальными заведениями (проверить поиском)

## Первый экран и анимации
- [ ] Заставка: точки собираются в значок кухни, текст проявляется, дальше живая LED-стена
- [ ] «Три боли»: переключатель «Без / С Goulash.tech» работает пальцем и мышью
- [ ] «Как это работает»: шаги едут вбок, курьер катится по линии; на невысоком ноутбуке — обычный список без наездов
- [ ] Пиксельные шторки на переходах тёмная → светлая: заметная заливка, без швов
- [ ] С включённым «Уменьшить движение» (настройки системы) всё статично и читается

## Видео (AC-28)
- [ ] Видео помогает показать продукт, без дефектов генерации (руки, двоение), подписи читаются
- [ ] Раскрывается по прокрутке, само идёт без звука, «Пауза» останавливает, «Включить звук» на iPhone действительно включает звук
- [ ] Качество на большом экране приемлемое

## Телефон и компьютер (AC-27)
- [ ] На телефоне нет горизонтальной прокрутки, шапка в одну строку, меню открывается
- [ ] Кнопки и поля удобно нажимать пальцем
- [ ] Все пять демо работают: вкладки, фильтры, кнопки, ползунки, «Сбросить демо»
- [ ] Проверено на реальном телефоне, а не только в окне браузера

## Форма
- [ ] Пустая отправка показывает ошибки под полями
- [ ] Телефон форматируется при вводе
- [ ] Видна загрузка на кнопке, дальше «Заявка отправлена» и «Отправить ещё одну»
- [ ] Адрес с `?simulate=error#form` показывает ошибку, «Повторить» работает, данные не теряются

## Публикация (AC-29)
- [ ] Корень сайта открывает страницу (без 404), неверный адрес показывает страницу 404
- [ ] Ссылка открывается в режиме инкогнито и с мобильного интернета
- [ ] Превью ссылки в мессенджере: обложка, заголовок, описание; во вкладке фавикон
- [ ] В сообщении при сдаче 5–6 строк о процессе (`docs/submission.md`)
